# E6: does privacy cost forecasting accuracy?

Generated by `npm run e6` on 2026-09-27: 13th Gen Intel(R) Core(TM) i5-13450HX (16 threads, pinned to logical CPU 2 (a performance core)), win32 10.0.26200, Node v22.10.0, OpenSSL 3.0.15+quic. Seed "veil E6 seed 1". Run time 62.3 s.

100 simulated homes (`src/load.ts`), 60 days of 5-minute totals, each reading clipped to ±10 kW. Forecast: tomorrow's peak total is the mean of the last 7 daily peaks; error is the mean absolute percentage error over days 8-60. The differentially private version adds Laplace noise of scale 10 kW / epsilon to every published total.

Veil check: all 288 rounds of day 1 were run through the protocol (N = 100, k = 38, t = 21); 288/288 published totals equal the exact totals, so Veil's forecast is the exact one. This is an invariant of exact aggregation, not an experimental result.
